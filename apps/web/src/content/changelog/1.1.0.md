### Added

- **Chat Mode on OpenCode**: turn on Chat Mode for OpenCode too. Its models
  are `provider/model`, its prompt arrives through the Waycar plugin rather
  than a launch flag, and Quick thinking does not apply (the TUI has no
  reasoning-effort flag). (#84)

### Fixed

- **First message to a new OpenCode Agent**: a chat message sent right
  after starting an OpenCode Agent on a herdr Host was acknowledged but
  never reached OpenCode, which ignores typing until its input box appears.
  Waycar now waits for that box before sending, and says "OpenCode is still
  starting" if it never shows up instead of losing the message.
