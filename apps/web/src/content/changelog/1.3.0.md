### Added

- **Start an agent with no connection**: New Agent now works while a Host is
  out of reach, such as when you have no signal. It offers the agents Waycar
  last found on that Host and says the agent starts when the Host connects. Tap
  **Start** and the launch is kept on your device; its card in the Console
  says it's waiting, and it starts on its own the next time Waycar is open
  and the Host connects. If it fails, the card says why, with **Retry** and
  **Delete**.
- **First message in New Agent**: type or paste a message, and add images
  and files, when you start an agent. Waycar sends it once the agent is
  ready, online or not.

### Changed

- **Waycar is free**: no subscription and no launch limit; every feature is
  free for everyone. The launch count earlier versions kept in your iCloud
  Keychain is deleted.

### Fixed

- **Back and Done in the Sample**: the Sample label no longer covers an
  agent's Back button or the Done button of the Sample's sheets.
- **Live Activity on Apple Watch**: the agent statuses in the Smart Stack
  stay readable when the watch shows its widgets light. The Live Activity
  is now always dark there, as it is on CarPlay.
