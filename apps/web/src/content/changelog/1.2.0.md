### Added

- **Apple Watch app**: see your Agents and their status on your wrist, read
  what an Agent last said, and answer by voice: tap the mic, speak, and your
  iPhone turns it into text on the device and sends it. Blocked Agents show
  the full command with Allow and Deny, and your Live Activity counts appear
  in the Smart Stack. The watch works through your paired iPhone and never
  connects to your Hosts itself. (#193, #206)
- **Waycar in CarPlay**: on iOS 26.4 and later, your Agents show on the car's
  screen, attention first (Blocked, Done, Working, Idle). Tap one and ask it
  anything out loud: Waycar sends your question when you pause, speaks the
  answer in a sentence or two, then listens for the next. Plain Yes/No command
  approvals can be allowed or denied by voice; risky ones are held. Pick the
  voice, speaking speed (0.75× to 1.5×), or an on-device Natural Voice (Beta)
  in Settings › CarPlay Voice. Speech is transcribed on the iPhone and nothing
  an Agent writes is shown on the car's screen. (#152)
- **Agent Progress**: a bar fills along the bottom of each Working Agent's
  card, so you can see which ones are nearly done. It counts the Agent's own
  plan steps (3/7) or shows its phase (Exploring, Building, Verifying,
  Wrapping up). The same estimate appears on the Agent screen, in CarPlay,
  on Apple Watch, and in Lock Screen and Dynamic Island rows. Needs AI
  Summaries and Waycar plugin 1.4.0 or later on the Host. (#189, #199, #210)
- **Queued messages and approvals**: a message you send while the Host is
  disconnected now waits on your phone as Queued, with its images and files,
  and goes out on its own when the Host is back, even after closing Waycar.
  Cancel or edit it any time. Allow and Deny on a Blocked Agent queue the same
  way, and go out only if the Agent is still showing the same prompt. (#151,
  #218)
- **Update Waycar on a Host from the app**: when a Host's Waycar plugin is too
  old for this app, Waycar says so on the Console and the Host's page. Tap
  Update, review the change, and Waycar runs the official installer over SSH,
  shows progress, and reconnects. Your pairing, keys and settings are kept.
  (#209)
- **Files and links from the terminal**: when an Agent prints the path of an
  image, PDF or Markdown file, a small strip under the terminal shows it,
  with thumbnails for images. Tap for Files & Links, a list of everything the
  Agent mentioned, newest first. Markdown opens rendered, with tables, code
  blocks and checklists, and images and PDFs open full screen and swipe
  between each other. (#144, #147, #205)
- **Agent Footer**: the band below the Toolbar on an Agent's terminal now
  shows its name and directory. In Settings › Agent Footer, add the git
  branch, model, context, cost, tokens/s and more, up to three lines, per
  device type. (#169)
- **Help inside the app**: the Waycar help pages now ship with the app and
  work offline. Settings › Help lists them by topic with search, and a
  question-mark button in Settings, New Agent, Scan to Pair and a Host's page
  opens the right topic. Tap Ask an Agent on any help page to start an Agent
  with that page attached. (#161, #166)
- **Twelve more agents**: Chat Mode now works with GitHub Copilot CLI, Qwen
  Code, Gemini CLI, Grok Build, Antigravity, Hermes Agent, Kilo Code, Cline
  and Muse. tmux status now covers those plus Cursor Agent, Devin CLI and Kiro
  CLI. Waycar won't type into an agent's sign-in or folder-trust screen, and
  Closed Sessions reopen the right session for each agent. A new Supported
  agents help page lists what each one supports. (#172)
- **AI Usage works for Claude over SSH**: Claude's usage no longer fails over
  SSH when it is signed in on a Mac Host. Waycar reads it through a small
  helper on the Host, and if the helper is missing, Fix it for me… starts an
  Agent that sets it up.
- **Git worktrees and Hosts**: closing the last Agent in a repository's main
  workspace now closes it together with its worktree workspaces, as herdr does
  on the desktop, instead of failing with "Could Not Close". Duplicate a Host
  from its card to reach the same machine on another network, and touch and
  hold an Agent card to Rename Tab….

- **Rate Waycar**: after you have used Waycar for a while, it occasionally
  asks, using Apple's standard rating prompt, once an Agent you sent a
  message finishes. Settings › About has a Rate Waycar link to the App Store
  review page any time. (#224)
- **Reddit SKAdNetwork attribution**: Waycar now reports installs, and
  later whether one became a Waycar Pro subscription, to Apple's own
  SKAdNetwork — the privacy-preserving signal behind Reddit's iOS ad
  attribution, with a copy to Singular, our measurement vendor. No ad SDK
  is in the app, no App Tracking Transparency prompt is shown, and no
  advertising identifier is read. See the privacy policy.

### Changed

- **Message Agent opens ready to type**: tapping 💬 now puts the cursor in the
  message field straight away, and ⌨ raises the terminal keyboard even when
  Message Agent was open with its keyboard down. (#228)
