### Added

- **Disable a Host**: turn off the switch on its Hosts row (or at the top of
  its Host page) and Waycar no longer connects to it or shows it in the
  Console. Its settings, cached Agents and Closed Sessions are kept, and its
  notifications still arrive. With iCloud Sync on, the switch syncs to your
  other devices. Turn it back on to reconnect. (#110)
- **Hosts sheet live gauges**: while the Hosts sheet is open, every
  connected Host's latency re-measures every 2 seconds, and a Linux or
  macOS Host's card shows live CPU, memory and swap gauges on the same
  schedule. A gauge turns orange at 80% and red at 95%; a Host without swap
  says None. Nothing shows for a Host that is not connected. (#134)

### Changed

- **Hosts sheet** shows each Host as its own card, like the Console's Agent
  cards: name and switch on top, address and connection below, and the
  live gauges underneath. (#134)
- **Settings** is quieter: row icons are gray instead of purple, and Hide
  Back Button moved into Settings › Terminal Appearance.
- **Opening a terminal** has its own moment. While an Agent's terminal
  connects, it shows the Agent's name and Host over a quiet field of dots
  in your terminal theme, and the first screen of output spreads out from
  the cursor. Reconnecting keeps the last screen readable under a light
  veil instead of a Reconnecting pill. A Host problem is spelled out in
  full, and Reduce Motion keeps it all still. (#96)

### Fixed

- **Alert Cancel buttons** are quiet gray on iOS 27.0.1 instead of purple,
  including Close Agent's Cancel. The alert drew its Cancel in the app's
  accent colour, which the earlier gray setting never reached. (#75)
- **Console bottom bar**: picking a Host or Workspace no longer leaves that
  item blank for a second or two. The menu used the item itself as the shape
  it opens from and closes back into, and the item changed (its name and
  colour) just as the menu closed, which sometimes left it undrawn until the
  next redraw. The item now stays drawn while the menu opens and closes over
  it, and shows the new choice straight away. (#93)
- **Closing several Agents at once** no longer fails every row with "Could
  Not Close Tab … TransportError error 22" when the Host is briefly
  reconnecting as the countdowns run out: the closes wait for the Host to
  come back and then go out. A close whose answer was lost with a dropped
  connection no longer reports a failure for a tab that did close, and the
  Close and Move alerts now say what went wrong in words. (#115)
- **Chat Mode Return key**: with a hardware keyboard attached, Return sends
  the message and Shift+Return starts a new line. Without one, as on an
  iPhone, Return starts a new line and the Send button sends. (#74)
- **Edit Draft caret**: restoring an undelivered message puts the caret
  after the restored text instead of at the start. (#74)
- **Mosh on a Host with more than one address**: a Host reachable at
  several addresses (a Mac on both Ethernet and Wi-Fi, say) now attaches
  over mosh instead of falling back to SSH. Mosh now uses the address SSH
  actually connected to. (#122)
