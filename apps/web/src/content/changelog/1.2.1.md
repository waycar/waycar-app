### Added

- **Share Waycar**: Settings › About has a **Share Waycar** row that opens
  the share sheet with Waycar's App Store link. Sharing the app is just
  that: nothing is offered or earned for it, and no personal invite code is
  created. If you have turned on "Share usage analytics", opening the share
  sheet is counted anonymously; nothing is counted otherwise, and who you
  share with is never known.

- **The free Launch limit is measured, anonymously**: if you have turned on
  "Share usage analytics", Waycar counts when the allowance refuses a
  launch, in counts only and never with which Hosts or agents were
  involved. Nothing is sent while that switch is off. Opening Waycar Pro
  from Settings on your own is not counted as hitting the limit.

- **The install command asks: install, or pair only?** On a fresh machine with a
  terminal it now asks whether to install the host tools or pair this computer
  only. Choosing pair only runs the Pairing Code from a temporary download and
  installs nothing, for machines where you may not install software;
  `--pair-only` does the same without asking. Invalid answers ask again, and
  Ctrl-D cancels without installing. (#257)

### Fixed

- **Closing the Pairing Code while a device was already connecting can no
  longer enroll that device silently**: the popup's close now removes the
  pending pairing under the same lock the enrollment commits under, so a
  late accept instead reports that the pairing is gone. (#257)

- **See each Codex account in AI Usage details**, with its own account label,
  limits, and VoiceOver description. Direct reads from CodexBar now include
  all configured Codex accounts when supported, rather than only the selected
  account. (#258)

- **Subscriber attribution stays reliable** when subscription status changes
  quickly: conversion updates now reach Apple in order. (#254)

- **Arrows and keys reach the Agent's terminal without the keyboard** on a
  hardware-keyboard iPad: with the on-screen keyboard down, plain keys,
  arrows, Tab and Return went to nothing, or moved the Agent list instead.
  The terminal now holds the keyboard connection as soon as it is on
  screen, including when the landscape sidebar opens later. Reconnecting
  a keyboard preserves Search Agents focus and an open Tools dock.
  Tapping the terminal still raises the on-screen keyboard; leaving it
  restores normal sidebar keyboard navigation.

- **The install command's pairing offer shows the QR in your terminal**: on a
  herdr Host it used to invoke the herdr plugin action, which printed herdr's
  JSON reply into the terminal and opened the QR in a herdr popup you might
  not be looking at. Answering yes now runs `waycar pair`, which draws the QR
  right where you ran the install command, on tmux and herdr Hosts alike.
  A Host without a terminal (an unattended run) no longer aborts the offer
  with a silent exit: it prints the `waycar pair` command instead.
