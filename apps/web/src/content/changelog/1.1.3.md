### Added

- **Last screen while reconnecting**: opening an Agent or Shell, or
  launching straight back into one, now shows its last screen under the
  Reconnecting veil instead of a blank connecting screen, until the live
  terminal draws. Waycar keeps this picture on the device for the eight
  terminals you used most recently, for up to a day (see the Privacy
  Policy). (#105)
- **Mosh stall indicator**: when a mosh terminal stops hearing from its Host
  for about six seconds, a Reconnecting pill shows over the live screen
  instead of the terminal freezing silently. A Host that stays silent for 65
  seconds reconnects the terminal over mosh, rather than leaving it frozen.
  When the Host answers again after an outage, Waycar reconnects it right
  away instead of waiting out its retry delay. (#105)
- **Several photos or files at once** in Message Agent: pick up to 10 per
  message. Each shows as a chip above the message (a thumbnail for images)
  with its upload progress, and a failed one offers Retry; tap X to remove
  one. Send appends their Host paths after your text, and you can send images
  with no text. On a Shell the path still goes in at the cursor. Dragged-in
  images join the same row instead of inline markers. While the card is
  closed, the Message Agent button shows a badge with the count (red on a
  failure), and items beyond 10 are reported instead of silently dropped. (#128)

### Changed

- **Faster return to an Agent**: Waycar now keeps each Host's SSH connection
  while the app is in the background and checks it with one quick request
  when you come back, dialing afresh beside it only if it is slow to answer.
  When a mosh terminal is torn down at the end of the background grace
  period, Waycar first starts a fresh mosh server for it, so coming back
  within about 50 seconds reattaches without any SSH work. The Agent you last
  viewed gets one ready too while the Console is open, so tapping it is
  quicker. A mosh session that still answers after a short trip away is kept
  instead of rebuilt. (#105, refs #27)
- **Terminals open sooner**: a terminal now starts as soon as the Host's SSH
  login finishes, without waiting for the Agent list to refresh, and runs
  ahead of background work such as summaries and backend checks. Each
  connection also needs fewer round trips: key login, the terminal's PTY
  request and every herdr request each save one, and several channels can
  open at once. (#105, refs #87)
- **Quicker first requests**: Waycar remembers each Host's home folder, so a
  new connection skips that lookup, and its herdr version, so the Agent list
  subscribes without waiting for the first check.
  Hosts start connecting as the app's window is being set up, including
  when it relaunches into a saved screen, instead of after it appears.
  (#105)
- **Network changes**: switching between Wi‑Fi and cellular now re-checks
  every Host at once and moves mosh terminals to the new network
  immediately. After a switch, a connection that died is noticed within
  seconds; otherwise within about 35 seconds instead of up to 45. (#105)
- **Mosh where it works**: Waycar remembers, per Host and network, whether
  mosh gets through, so an Agent you relaunch into rides mosh from its first
  attach and a network that blocks UDP goes straight to SSH. Use SSH Instead
  now lasts across network changes. (#105)
- **Image and file uploads** no longer show a banner or copy the path to the
  clipboard automatically: the chip shows the status, and a long press on a
  ready chip offers Copy Path. (#128)
- **Alert Cancel buttons on iOS 27** are the app's violet again instead of
  gray; iOS 26 and earlier keep the gray Cancel. (refs #75; PR #137)

### Fixed

- **Returning to a terminal**: coming back to the app no longer flashes
  Connection Paused for a moment. The terminal keeps its last screen while it
  reconnects. (#105)
- **Hosts with an unreachable address**: when a Host name resolves to
  several addresses and the first does not answer, Waycar now tries the next
  one a quarter second later (Happy Eyeballs) instead of waiting out half the
  connection timeout. (#105)
- **Agent shown as live too early over mosh**: the loader no longer clears
  on mosh's own blank first frame, a moment before the Agent's screen
  arrives. (#105)
- **Closing or moving several Agents at once on a tmux Host** running tmux
  3.5 or older no longer fails some of them with "Could Not Close Tab" or
  "Could Not Move" when one of them takes the last window of the session
  Waycar's tmux connection is attached to. tmux ends that connection and
  drops the requests it had not read yet; Waycar now sends a dropped close,
  rename or read again on the new connection, and checks where a dropped
  move left the Agent before moving it again. Typed input and new Agents
  are never sent twice. (#131)
- **Live Activity pushed twice**: two Agent status changes arriving a moment
  apart could each push the same Live Activity update when the second came
  in while the first was still sending. The plugin now sends one at a time
  and the later change sees what was already sent. (#140)
