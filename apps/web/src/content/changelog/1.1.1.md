### Added

- **Console multi-select**: long-press an Agent and choose Select to check
  several Agents, across Hosts, and Close, Pin, Mark Read or Unread, or Move
  them together. Each closed row gets the usual undo countdown; Move works
  within one Host and says why when the selection spans Hosts.

### Changed

- **Console bottom bar** is tighter: the New Agent button is now a smaller
  outlined accent circle (transparent inside, purple ring and +) instead of
  a large filled one, and on iPad the bar sits on the screen's bottom edge
  with just enough room around its row. (#83)
- **Notification question**: if iOS hasn't asked you about notifications
  yet, Waycar's one-time notification question, and the explainer behind
  Settings › Notifications › Enable Notifications, now have one button,
  Continue, which brings up iOS's own question. Your answer there decides
  whether Waycar turns on notifications and Live Activities for your Hosts.
  If notifications are already allowed, the question still offers Turn On
  and Not Now. (#98)
- **Chat Mode file previews**: a file an Agent attaches in Chat Mode now
  opens as text unless it's a PNG, JPEG, GIF, HEIC or WebP image, a PDF, or
  a video or audio file, the same rule as files opened from the terminal.
  Web pages and SVG files no longer render in the app. (#98)
- **Jump to the beginning or end**: the button that appears after a long
  scroll now sits against the right edge of the Agent's terminal, a tenth of
  the way up from the bottom, as a small up or down tab, instead of floating
  partway up the screen and in from the edge. (#94)

### Fixed

- **Console Host rows**: a Host the app cannot reach no longer shows
  "Waiting for you to trust" its host key; with no answer from the Host
  there is no key to trust, so the row shows the connection failure. The
  wait still appears when the Host answers with a key you have not trusted
  yet, and the Host connects on its own once you trust it. (#117)
- **Host latency badge**: no longer re-measures and redraws every 30
  seconds while a Host sits idle. The keepalive ping still runs on that
  schedule to prove the connection is alive, but each one costs a full SSH
  channel open, exchange and close, so repeating it just to refresh a
  number was needless churn and, on a slow network, a flickering
  four-digit figure. The badge now updates only when it means something
  changed: at connect and when the app returns to the foreground. (#87)
- **Slow first requests on distant Hosts**: the SSH client socket did not set
  `TCP_NODELAY`, so libssh2's back-to-back small packets (EOF then close,
  open then data) waited for the server's delayed ACK before each second
  write — a stall of roughly one round trip plus up to 200 ms on cellular,
  two or three times per foreground revalidate and seven to ten per cold
  launch. Every request now sends its packets immediately. (#87)
- **iPad hardware keyboard**: the Console's bottom bar no longer floats
  above the screen edge while you type in an Agent's terminal; the
  keyboard's floating shortcut bar used to push it up. (#79)
- **iPad hardware keyboard**: while an Agent's terminal has the keyboard, the
  arrow keys go to it instead of moving the Agent list, Return and ⌘Return
  submit, and Shift+Return inserts a newline (Ctrl+J, which omp and Claude
  Code read as a new line). Leave the terminal and the arrow keys move
  through the list again. (#80)
- **Faster first latency number**: the Hosts-list badge used to time the
  remote `$HOME` lookup — and the SSH session setup that comes with the
  connection's first exec — inside the measured ping on every new
  connection, so cold launch and foreground return read 2–3 round trips
  high. Waycar now resolves the socket path as the connection opens, before
  the clock starts, and the badge measures the ping alone. (#87)
- **Chat greeting**: a new chat's greeting no longer switches to a
  different one while the chat is open. About half of all chats did.
- **Save to Photos**: Save Image and Save Video in the share menu, for a
  chat's media and for files opened from the terminal, now ask to add to
  your photo library instead of failing. (#98)
- **Paywall at large text sizes**: at the two largest standard text sizes
  (xxLarge and xxxLarge), Terms of Use and Privacy Policy now appear at the
  top of the paywall, so they stay above the plan buttons on smaller
  iPhones. (#98)
- **Restore Purchases**: Settings › Subscription › Restore Purchases now
  always shows a result: that Waycar Pro is active, that this Apple Account
  has no active Waycar Pro subscription, or the error if the restore
  failed. (#98)
- **Setup guide**: the steps for adding your first Host now say a Host runs
  herdr or tmux 3.2 or later, and step 4 no longer says to run the install
  command in herdr, since a tmux Host shows its Pairing Code in the
  terminal. The Pairing Code scanner also says "on your Host" instead of
  "herdr". (#98)
- **.m4v videos from the terminal**: tapping an `.m4v` path in an Agent's
  terminal now plays the video instead of showing it as text. (#98)
