### Added

- **Turn on notifications**: when you return to the Console or reopen
  Waycar after spending time on an Agent, Waycar asks once whether to turn
  on Agent Notifications and Live Activities. Turn On sets both up for every
  Host on this device, and for Hosts you add later; Not Now means it won't
  ask again. It also shows for people who have used Waycar before but never
  turned these on. (#71)
- **Chat Mode**: turn on Chat Mode in New Agent for Claude Code, Codex, OMP
  or Pi, and the Agent opens as a chat instead of a terminal: it greets you
  ("What are we working on today?" and friends), then shows your messages,
  the Agent's final reply to each one, and a status line showing what it is
  doing. When it needs you, Allow, Cancel or Show Terminal answer it right
  there. The Chat Prompt that asks for short replies is editable in
  Settings, notifications and the in-app banner show the reply itself (or
  the error, when a turn fails without one), and a chat started on one
  device opens as a chat on your others. Images the Agent opens during a
  turn show above its reply, and so do images and videos the reply names (a
  file on the Host or an https link); tap one to view it full screen. On the
  Console, a chat badge marks Chat Mode Agents and closed chats, and the
  Chat pill lists only them. A chat keeps a copy of its messages on the
  device, so it opens with them at once, and a read that fails is retried
  until the conversation is back. Settings › Chat Mode also picks the model
  for each harness and Quick thinking, on by default, for faster replies.
  Needs the updated Waycar plugin on the Host. (#52, #54, #57, #60)
- **New Chat**: touch and hold the Waycar icon › New Chat starts a chat at
  once with the Settings › Chat Mode defaults (Host, Workspace and Agent;
  Last Used by default, and when the chosen Host was removed) and the
  keyboard up. A Workspace that is gone is made again in its folder. When
  the defaults can't be used, or the Host isn't ready within 20 seconds, the
  New Chat sheet opens with Chat Mode on. With no Hosts it just opens
  Waycar. (#54)
- **tmux Hosts**: Waycar now works with tmux 3.2 or later as well as herdr.
  A tmux Host works like a herdr Host: your tmux sessions show up as
  Workspaces, and you can start, open, message, rename and close Agents and
  Shells from the phone. Opening one shares the window with your desk
  instead of taking it over. On a computer with both, herdr Agents and tmux
  sessions appear together in one list; New Agent starts on herdr unless you
  pick tmux for that Host. Live status and Blocked/Done notifications come
  from Status Hooks that the same install command adds to Claude Code,
  Codex, omp, pi and opencode; Codex asks you to review them once in its
  `/hooks` screen. When tmux has no sessions running, Start Session opens
  one from the Console. On a computer with both, if herdr or tmux fails it
  shows its own issue with Retry while the other keeps working. (#62)
- **Jump to the beginning or end**: keep scrolling an Agent's terminal and
  a button appears near its bottom corner that scrolls the rest of the way
  for you: back to the start of the conversation when you were scrolling
  up, down to live output when you were scrolling down. Dragging the
  terminal stops it partway. (#58)

### Changed

- **Quiet cancels**: Cancel and dismissive buttons in alerts, dialogs and
  sheets, and the symbols in the Agent actions menu, are now a quiet gray on
  every iOS version, so the primary violet action and destructive red stand
  out. (#75)
- **App icon**: the default icon is now the caboose in Waycar's brand violet.
  The green caboose is still in **Settings › App Icon** as Phosphor. (#54)
- **Brand colors**: buttons, links, toggles and selection now use Waycar's
  violet, as on waycar.dev, instead of iOS blue and green. (#54)
- **AI Usage pace estimate**: the AI Usage sheet now shows CodexBar's own
  estimate under each gauge — "14% in reserve · Lasts until reset" when you
  are using the window slower than it runs, or "20% in deficit · Runs out in
  2d 4h" when you are on track to run out before the window resets. The
  existing Show Pace switch turns it off.
- Settings › About › Acknowledgements lists more of the open-source
  components in the terminal engine.
- The terminal engine no longer includes GNU gettext, which it never used
  in Waycar. It is now built by us from the same Ghostty code, without it.
- **AI Usage is on for one Host by default**: when AI Usage is already on
  for a Host, another Host where CodexBar is found starts with it off, so
  the same AI accounts are not asked twice as often (which can cause
  rate-limit errors). Turn it on for more Hosts, or for another Host if you
  remove the one that is on, on each Host's page. Hosts whose AI Usage
  settings you never changed are set up the same way the next time Waycar
  finds CodexBar on them. (#51)
- **No Host yet**: the setup steps are shorter and say each thing once:
  install herdr on your first Host, turn on SSH, optionally install mosh
  (with links to Apple's Remote Login help and mosh.org), then run the one
  install command in herdr and tap Scan to Pair, or tap Add Manually to
  type the address. The Console's bottom bar stays hidden until you add
  your first Host; Settings is the gear beside "Add Your First Host". (#44)
- **Usage analytics**: Waycar asks once, on first launch, whether to share
  usage analytics, and sends nothing until you tap Allow. The Settings
  switch is now called "Share usage analytics".
- **AI Summaries** stay off until you choose Turn On. If you have not chosen
  yet, Waycar asks when you turn on notifications for a Host in Settings,
  and shows which AI companies get the last 60 lines of an Agent's screen:
  Anthropic, OpenAI, or OpenRouter, which passes it to Google or OpenAI
  models. Not Now keeps them off, and Waycar does not ask again. The AI
  Summaries switch in Settings asks the same way.
- **Waycar Pro**: the paywall shows Terms of Use and Privacy Policy links,
  and how to cancel, near the top.
- **Waycar Pro**: the paywall shows $5 a month and $40 a year, without
  cents. Prices that aren't whole, as in some countries, keep their cents.
  (#59)
- **Privacy policy**: names OTREVA, LLC, explains the analytics choice and
  the AI Summaries opt-in, and adds sections on service providers,
  children and your rights.

### Fixed

- **Chat Mode** chats stay chats when herdr restarts or is upgraded. herdr
  brings each Agent back in a new terminal, which the chat no longer
  recognized. herdr's restore starts the Agent without the Chat Prompt, so
  its replies may run longer until it is started again in Chat Mode. Rerun
  the Waycar install command on the Host so notifications keep carrying the
  reply too. (#69)
- **Pair device** no longer cuts off the bottom of the QR when the
  terminal's text is zoomed in. When the usual QR doesn't fit, the popup
  draws a more compact one; when even that doesn't fit, it asks you to zoom
  out or enlarge the window instead of showing a QR that can't be scanned,
  and draws it as soon as it fits. Rerun the Waycar install command on the
  Host to get it. (#65)
- **Trust this Host?** waits for your answer however long you take, even
  behind iOS's Save Password prompt, instead of closing itself after a
  minute. Tapping Trust late now connects: Waycar opens a fresh connection
  instead of using the one the Host already closed while you decided.
- A Host's checks no longer say "Could not reach the Host over SSH… (the SSH
  connection is no longer reusable)" when the Host was only slow to list its
  sessions, and Reconnect on the Host page reruns failed checks instead of
  leaving the old failure on screen.
- In Settings › Toolbar, the Add Item… list and a Custom Key opened from
  Your items no longer close by themselves after you scroll down the page.
  (#55)
- The Close Agent confirmation and Open Terminal's list of shells show in
  the middle of the screen instead of in a bubble pointing into the
  terminal. (#47, #49)
- With one Host, the Console's bottom bar now shows the Host menu too,
  instead of an empty space at the far left. (#46)
- A new Host no longer shows a red "host key is not trusted" error while
  Waycar asks you to trust it; the Console connects as soon as you tap
  Trust.
- A Host typed as an IPv4 address now connects on IPv6-only (NAT64)
  networks, and IPv6 addresses in [brackets] work.
- SSH errors use plain words instead of internal code names.
- Mosh timestamps count from when Waycar started, not from when the
  device booted.
