With a hardware keyboard attached, Waycar has shortcuts for moving between agents, searching, and sending.

## Shortcuts

| Shortcut | Action |
| --- | --- |
| ⌘1 to ⌘9 | Select the agent at that position in the list |
| ⌘[ | Previous Agent |
| ⌘] | Next Agent |
| ⌘F | Search Agents |
| ⌘N | New Agent |
| ⌘, | Settings… |
| ⌘⇧H | Hosts… |
| ⌘E | Toggle Message Agent (switch between Direct Input and the Composer) |
| ⌘Return | Send |
| ⌘W | Close Agent View |
| ⌘⌃S | Show or hide the sidebar (iPad) |
| ⌘+ and ⌘− | Make the terminal text larger or smaller (while the terminal has the keyboard) |

## When each one works

- ⌘1 to ⌘9 work only for agents that are in the visible list. ⌘[ and ⌘] need at least one agent.
- ⌘E and ⌘W need an open agent.
- ⌘Return sends the Composer's draft when the Composer has focus and has text. When the terminal holds the keyboard, it presses Return there.
- ⌘F, ⌘N, ⌘, and ⌘⇧H always work.

## Open Help

On iPad with a keyboard, press ⌘? to open the Help menu search, then choose **Waycar Help**. Waycar Help has no shortcut of its own. It's also in the **Help** menu of the menu bar. On any device you can open it from **Settings** › **Support** › **Help**. See [Get help and contact support](/help/get-help).

## Typing in the terminal

While an agent's terminal has the keyboard:

- Arrow keys go to the terminal, not the agent list.
- Return and ⌘Return submit.
- Shift+Return inserts a new line (Ctrl+J, which omp and Claude Code read as a new line).

In [Chat Mode](/help/chat-mode), Return sends.

## Good to know

With more than one window open, shortcuts act on the window you're using. See [Multiple windows and Stage Manager](/help/multiple-windows).
