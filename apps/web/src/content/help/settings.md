Settings holds Waycar's app-wide choices: how the Console and terminal look, notifications, sync, and support. A Host's connection, backend, mosh and AI Usage options live on that Host's page instead. See [A Host's page and checks](/help/host-page).

## Open Settings

- **From the Console:** tap **Settings** in the bottom bar.
- **Before you add a Host:** the bottom bar is hidden, so tap the gear beside **Add Your First Host**.
- **With a keyboard:** press ⌘, (the **Settings…** command). See [Keyboard shortcuts](/help/keyboard-shortcuts).

Tap **Done** to close Settings.

## What each row does

Rows appear in this order. Some show only where they're supported.

| Row | What it does |
| --- | --- |
| **Agent List Fields** | Which lines each agent card shows. See [Agent card fields](/help/agent-card-fields). |
| **Toolbar** | The keys above the keyboard. See [The Toolbar](/help/toolbar). |
| **Agent Footer** | What the band under the Toolbar shows. See [The Agent Footer](/help/agent-footer). |
| **Chat Mode** | **Chat Prompt**, models and New Chat defaults. See [Chat Mode](/help/chat-mode). |
| **CarPlay Voice** | The voice CarPlay reads with. Shown on iPhone, on iOS 26.4 or later. See [Choose the voice](/help/carplay#choose-the-voice). |
| **Notifications** | Per-Host alerts, Live Activities and **Custom Push Relay**. See [Notifications](/help/notifications). |
| **Appearance** | The app's look: **System**, **Light** or **Dark**. |
| **App Icon** | Pick an alternate icon. Shown where iOS supports it. See [App icons](/help/app-icons). |
| **iCloud Sync** | **Sync with iCloud**, **Check Now** and key replacement. See [iCloud Sync](/help/icloud-sync). |
| **Terminal Appearance** | Terminal themes, font and **Hide Back Button**. See [Terminal themes, fonts, and zoom](/help/terminal-appearance). |
| **CodexBar** | How AI Usage is shown. See [AI Usage with CodexBar](/help/ai-usage). |
| **AI Summaries** | One-line summaries on cards and notifications, off until you turn it on. See [AI Summaries](/help/ai-summaries). |
| **Share usage analytics** | Simple usage counts, on only if you allowed it. See [Privacy and analytics](/help/privacy). |
| **Support** | **Help**, **Email Support** and **Community on Reddit**. See [Get help and contact support](/help/get-help). |
| **About** | **Version**, **Changelog**, **Acknowledgements** and **Privacy Policy**. See below. |

## Help

**Settings** › **Support** › **Help** opens Waycar's help pages inside the app, with search. Many feature screens also have a **Learn More** button (a question mark) that opens the help page for that screen. See [Get help and contact support](/help/get-help).

## About

- **Version** shows the app version and, in parentheses, the build number. Quote both when you ask for help.
- **Changelog** lists what changed in each version, newest first; scroll down to go back to earlier versions. The same list is on [waycar.dev/changelog](/changelog).
- **Acknowledgements** lists the open-source components Waycar includes, each with its licence. Tap one to read the full notice.
- **Privacy Policy** opens the [privacy policy](/privacy).

## Good to know

- Many of these choices follow you to your other devices with iCloud Sync. See [What syncs](/help/icloud-sync#what-syncs).
- Accessibility features come from iOS settings, not Waycar's. See [Accessibility](/help/accessibility).
