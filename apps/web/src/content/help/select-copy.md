Touch and hold text in an agent's terminal to select it right where it is, with draggable handles and the system Copy menu. Waycar picks the word under your finger, or a whole link or file path, so you rarely need to adjust the handles.

## Copy text from the terminal

1. Touch and hold the text you want.
2. Drag the handles to widen or narrow the selection.
3. Tap **Copy** in the menu.

The selection uses Waycar's violet, as on waycar.dev.

## Select a link or a file path

Touch and hold a link or a path to select the whole thing at once. That includes a long path that the agent, a bordered box, or the narrow screen broke across lines.

If you select exactly such a broken path across its lines, the menu offers **Preview** too, so you can open the file. Selecting a list of several paths does not offer Preview.

To open a link or preview a file without selecting it, tap it instead. See [Files and links](/help/files-and-links).

## Paste into the terminal

To paste what you copied into the agent, tap the **Paste** key on the Toolbar. With **Message Agent** open, Paste goes into your draft instead. See [The Toolbar](/help/toolbar#paste).

## Good to know

- Swiping from the left edge goes back even while text is selected. Only a selection handle sitting right at the left edge takes the drag there, so it stays easy to grab.
- A Markdown file you open from the terminal can flip to its raw text with **Show Raw Text**, which you can select and copy too.
